# Bamlehri Aqua site (React + Vite)

1. Unzip `final transition.zip` and copy all `ezgif-frame-XXX.jpg` files into `public/frames/`
2. `npm install`
3. `npm run dev`   (open the address it prints)
4. `npm run build` for the production version (output in `dist/`)

Where things are
- `src/components/Loader.jsx`  particle intro (click / tap / Enter skips it)
- `src/components/Hero.jsx`    sections 1 + 2: frame sequence + "blueora" + tagline (settings at the top of the file)
- `src/App.jsx`                section 3 (blue) and section 4 (red) are at the bottom
- `src/styles.css`             colours, fonts, header
